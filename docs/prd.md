# AIビジネス はじめの一歩 — 初心者向けMVP仕様

ステータス: Product Agent策定済み・実装前。

## 課題・対象・提供価値

生成AI初心者が、AIを使った事業づくりで何を学び、どの順番でアイデアを整理し、次に何を実行するかを判断しにくい、という課題仮説を扱う。

対象は、生成AIの利用経験が少なく、初めて自分の小さな事業アイデアを整理したい日本語話者の個人。MVPでは1人につき1つのアイデアを扱う。

短い日本語教材と記入式ワークを順番に進めるだけで、誰の何を解決する事業かを1枚に整理し、見込み顧客に確かめるための次の行動を1つ決められる。収益化や事業成功を保証するものではない。

## 最小の利用フロー

初回表示 → 生成AIの基礎を学ぶ → 顧客と困りごとを記入 → 提供価値とAIの使い方を記入 → 検証計画を記入 → 一覧で確認 → 次の検証行動に進む。途中で閉じても同じブラウザーで再開する。

## 機能

### F1: 4段階の学習ロードマップ

1. 生成AIの基礎と注意点
2. 顧客と困りごと
3. 提供価値とAIの使い方
4. 小さな検証計画

各段階は短い教材、具体例、記入ワーク、完了ボタンで構成する。未着手・進行中・完了を表示し、過去の段階を再編集できる。

### F2: 1件の事業アイデア整理

顧客、困りごと、提供価値、AIを使う作業、確かめたい仮説、検証する行動、完了の判断条件を入力し、一覧で確認する。

各項目は必須で1〜500文字。第1段階では「生成AIで試したいこと」を入力し、事実確認と機密情報を入力しない注意点を確認する。

### F3: 同じブラウザーへの進捗保存

入力内容と段階ごとの完了状態をlocalStorageへ保存し、再訪時に再開する。保存成功・失敗を表示し、保存できない場合も現在の画面では編集を続けられる。全データの削除には確認操作を設ける。

### F4: 次にやるべき一手

最初の未完了段階に対応した行動をホーム画面に常に1つだけ表示する。全段階完了後は利用者が記入した「検証する行動」を表示する。

### F5: 人間が操作できる日本語プレビュー

ローカル起動できるWeb画面を提供し、空の状態から学習、記入、完了、再読み込み、再開、削除まで操作できる。開発者向けの計測確認機能でローカルイベントを確認できる。

## 受入条件

- **AC1:** 初回表示で日本語の4段階、進捗0/4、最初の一手が見える。
- **AC2:** 空白、501文字以上、または第1段階の確認チェックが未選択なら完了できず、理由を表示する。
- **AC3:** 段階を順に完了すると進捗が1/4から4/4へ増える。完了済み段階は編集できる。
- **AC4:** 全段階完了後、入力した7項目を一覧表示でき、各項目の編集画面へ戻れる。
- **AC5:** 保存成功後に再読み込みすると、入力内容・完了状態・次の一手が復元される。
- **AC6:** 保存不能やデータ破損時は理由と復旧手段を表示し、入力を継続できる。
- **AC7:** 削除確認を取り消すと保持され、確定すると入力・進捗・計測履歴を削除する。
- **AC8:** 最初の未完了段階の行動だけを表示し、ボタンで該当ワークを開く。
- **AC9:** 幅390pxと1280pxで主要操作が横スクロールなしに使え、キーボード操作とフォーカス表示が機能する。
- **AC10:** 計測イベントに入力本文や個人情報を含めず、再読み込みだけでイベントを重複発火しない。

## 最小限の計測

- `roadmap_started`: 最初のワークを開始した時
- `step_completed`: 段階が未完了から完了へ変わった時
- `next_action_opened`: 次の一手を押した時
- `progress_resumed`: 保存済み内容を復元して再開した時

イベントはブラウザー内の直近200件に限定し、外部送信しない。ランダムな匿名ローカルIDのみを使い、入力本文・メール・IPアドレスは記録しない。

## 構成と対象外

固定コンテンツを含む単一のWebフロントエンドとlocalStorageで実装する。サーバーや外部APIを前提にしない。

対象外は生成AI APIによる回答生成、ログイン・課金、複数アイデア管理、端末間同期、外部サービス連携、事業成功や収益の自動判定。

## 検証計画

生成AI初心者5名による操作観察を行い、20分を目安に初回完了と再読み込み後の復元を確認する。暫定成功基準は、5名中4名以上が操作代行なしで4段階を完了し、顧客・困りごと・次の検証行動を自分の言葉で説明できること。

顧客調査、競合比較、支払意思、教材の学習効果は現時点で未検証であり、少人数の結果から市場需要や事業成功を断定しない。
