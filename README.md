# AI Business Starter

生成AI初心者が、AIを使った小さな事業を始めるための考え方と手順を、
4段階のワークで学べる日本語Webアプリケーションです。

## MVP

- 生成AI利用時の基本と注意点
- 顧客と困りごとの整理
- 提供価値とAIを使う作業の整理
- 小さな検証計画の作成
- ブラウザー内への進捗保存
- 次に行う1アクションの提示

詳細は [Product Agentが作成したPRD](docs/prd.md) を参照してください。
